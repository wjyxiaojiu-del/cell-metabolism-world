# 01 — 修正学习模式三组高风险机制图

**What to build:** 学习者打开脂肪酸合成、氨基酸碳骨架、核苷酸降解时，看到与教材主线一致、区室清楚、入口和出口可读的机制图。

**Blocked by:** None — can start immediately

**Status:** ready-for-agent

- [ ] 脂肪酸合成明确柠檬酸输出、胞质 ACC/FAS、ER 延长/去饱和的空间关系。
- [ ] 氨基酸碳骨架明确七类中央代谢入口，并区分生糖、生酮和 TCA 补充。
- [ ] 核苷酸降解从胞质核苷酸池开始，明确补救回收与嘌呤/嘧啶降解，不出现溶酶体 DNA/RNA 误导。
- [ ] 三张图保留现有教材信息图风格，图片加载和关键文案测试通过。
