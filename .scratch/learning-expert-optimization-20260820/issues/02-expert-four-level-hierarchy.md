# 02 — 固定专家模式四级场景层次

**What to build:** 专家模式按完整细胞总览、细胞器总览、具体区室、通路机制图四级浏览；用户不会在父级看到属于子级的反应线路堆叠。

**Blocked by:** None — can start immediately

**Status:** ready-for-agent

- [ ] 完整细胞总览只显示结构入口，不显示核心通路线路。
- [ ] 细胞器总览只显示本细胞器及其子区室入口。
- [ ] 具体区室显示该区室线路和通路入口。
- [ ] 第四级机制图显示该通路的反应、酶、载体和辅酶叠加。
- [ ] 返回操作逐级退回，不跳级；21 条核心通路导航回归通过。
