# 2026-08-20 学习模式与专家模式优化规格

## Problem Statement

学习模式中，脂肪酸合成、氨基酸碳骨架、核苷酸降解的教材机制图仍有区室或入口表达不清的问题。专家模式虽然反应数据和几何门禁已通过，但完整细胞、细胞器、子区室和通路机制图之间的责任边界仍不够明显。

## Solution

保留现有教材信息图风格，只修正会误导学习的机制图；同时固定专家模式四级浏览结构：完整细胞总览只提供结构入口，细胞器总览提供细胞器内部入口，具体区室提供该区室通路，通路机制图才显示反应叠加层。

## User Stories

1. 作为学习者，我要看到脂肪酸从柠檬酸输出到胞质 ACC/FAS，再到 ER 延长或去饱和的正确空间关系。
2. 作为学习者，我要区分氨基酸碳骨架的生糖、 生酮和 TCA 补充入口，而不是只看到一个拥挤的 TCA 圆环。
3. 作为学习者，我要从胞质 AMP/GMP/UMP/TMP 等核苷酸开始理解补救回收和嘌呤/嘧啶降解，不把它误解为溶酶体 DNA/RNA 水解。
4. 作为专家模式用户，我要在完整细胞总览中只看到结构入口，不被通路线路堆叠干扰。
5. 作为专家模式用户，我要在每一级看到清晰的当前场景、父级和下一级入口。
6. 作为专家模式用户，我要只有在第四级通路机制图中看到反应方向、酶、载体和辅酶叠加。
7. 作为教师，我要每条跨区室通路的底图、区室标签、节点和反应方向与权威教材主线一致。

## Implementation Decisions

- 学习模式机制图的验收以区室、入口、出口、关键酶和反应方向为准；图片风格保持当前科学信息图风格。
- 专家模式场景层级不再由通路是否属于子场景隐式推断，而是显式维护当前层级、父级和可进入子区室。
- 完整细胞总览不渲染核心通路线路；细胞器总览只渲染区室入口；具体区室渲染本区室线路；机制图渲染通路反应叠加。
- 任何跨区室通路在父级只显示入口，不提前渲染跨膜反应细节。
- 反应数据继续以可审计 TSV 为来源，编译产物不得手工编辑。

## Testing Decisions

- 以学习模式公开入口验证三张机制图的图片加载、科学标题、区室文案和关键步骤。
- 以专家模式公开点击路径验证四级场景、父级返回、子区室入口和机制叠加层。
- 保留现有 21 条核心通路数据/几何门禁，新增测试只断言用户可见行为，不绑定内部函数。

## Out of Scope

- 不重绘已经与教材主线一致的学习模式图片。
- 不上传实验稿、拒绝稿或未被页面引用的源图。
- 不改动手机适配目标；专家模式仍以桌面和 iPad 为主。
