## 处置结论

| 原问题 | 处置 |
|---|---|
| 封面键盘焦点泄漏 | 封面移到应用主体外；主体在封面阶段使用 `inert` 和 `aria-hidden`，模式与检查器继续同步隔离 |
| ATP 合酶端点区室错误 | `oxphos.tsv` 的 H⁺ 明确到线粒体膜间隙，ATP 明确到线粒体基质 |
| 编译器按端点静默去重 | 新增完整反应身份；端点、酶、反应式和可逆性相同时才合并，内容不同的 6 组记录分别保留 |
| 验证流程覆盖源数据 | 导入/导出工具默认只读预览，写入必须显式使用 `--write`；编译器增加 `--check` |
| HANDOVER 建议删除运行时依赖 | 文档已明确 `scene-data.js` 支撑学习模式和场景导航，迁移完成前不得删除 |
| `transport` 无对应场景 | 新增第 55 个导航入口，双击筛选可进入线粒体内膜场景 |
| 可逆字段与箭头不一致 | 修正 6 行反应式，并在校验器中增加双向一致性门禁 |
| HANDOVER 统计过期 | 当前统一为 348 TSV 行、290 节点、323 编译反应、55 通路、51 行待审校 |
| 搜索能力文档过期 | 已标记节点、参与物、酶、反应式和通路搜索均已实现 |
| 科学报告仍写“关闭 72 行” | 原 58 行已逐项复核：7 行提升、51 行保留；原 72 行仅作为历史审核范围 |
| ARIA 与 landmark | 移除 `button[role=listitem]`，增加唯一 `main`，检查器和隐藏模式使用 `inert` |
| 参与物别名失效 | 别名表统一使用归一化键；补充 F-1,6-BP、1,3-BPG、Cyt c 和 Asp 回归测试 |
| NAD(P)H 被并入 NADPH | 归一化保留有化学意义的括号，非特异性 NAD(P)H/NAD(P)⁺ 与 NADPH/NADP⁺ 分开建目 |
| 氮同化入口区室错误 | 硝酸还原反应移至细胞质，并补入一条待审校的亚硝酸盐质体转运边 |
| 搜索结果被长名称抢占 | 学生与专家模式均先匹配完整名称，再执行包含匹配；无结果通过 `aria-live` 公告 |
| 学生模式 SVG 嵌套交互 | 三张交互图由 `role="img"` 改为 `role="group"`，并提高低对比度辅助文字颜色 |
| 校验器行号偏移 | TSV 读取器保留物理行号，节点、反应和坐标校验均报告源文件实际行号 |
| HANDOVER 尾部过期 | 交接日期更新为 2026-08-07，并明确转录任务为 0 |
| 审校状态与表示类型混用 | 新增 `docs/scientific-review-policy.md`，状态只允许待审校/已核对/已终审，表示类型和证据单独记录 |
| 引用真实性缺少门禁 | 新增 `tools/check-citations.js`；修复 Rhea `ASK=false` 误判，并加入超时、受控并发及无效/接口失败分类 |
