# 转录格式

把手写代谢总图录成结构化数据的操作说明。

原图是手写矢量，标签只存在于笔画里，OCR 和文字层都提取不出来（54 个通路名只认出 1 个）。
所以转录只能人工做。这份格式的目标是让你**只写你才知道的东西**，其余全部自动。

## 你写什么，不写什么

| 你写 | 自动 |
|---|---|
| 底物、产物的名字 | 节点 ID |
| 区室（中文，或任一同义词） | 节点坐标 |
| 酶 | 同物质跨区室的互链 |
| 可逆与否 | 场景归属 |
| 反应式（有辅因子时） | 通路标签的合并 |

**不要填坐标。** 位置由算法在每个细胞器的椭圆范围内计算。
只有当你明确不满意某个节点的位置时，才去 `data/layout-overrides.tsv` 里写死它。

## 三种文件

```
data/reactions/*.tsv      主要工作在这里。一个文件一条通路。
data/nodes/*.tsv          只有需要额外属性的节点才写（膜侧、别名、物种、组织）。
data/layout-overrides.tsv 手工坐标。例外情况才用。
```

绝大多数节点由反应文件自动推导 —— 你写了 `葡萄糖 → 葡萄糖-6-磷酸`，两个节点就都有了。

## 反应文件长什么样

```
#	通路: 糖酵解	Glycolysis
#	默认区室: 细胞质
#	来源: PDF 左上糖代谢区
底物	产物	酶	可逆	反应式	审校	备注
葡萄糖	葡萄糖-6-磷酸	己糖激酶	否	葡萄糖 + ATP → G6P + ADP	已核对	限速步
```

必填只有 **底物** 和 **产物**。其余留空都能跑。

- **可逆**：只能写 `是` 或 `否`，留空按 `否`
- **审校**：`已核对`、`已终审` 或 `待审校`
- **反应式**：有辅因子或多产物时才写，否则留空

分隔符是**制表符**，不是逗号 —— 因为 `果糖-1,6-二磷酸`、`5,10-亚甲基-THF` 这类名字里有逗号。
现有 304 个名字里没有一个含制表符，所以 TSV 是安全的。

## 区室怎么写

文件头写一次 `默认区室`，整个文件的节点都归它。**只有跨区室的那几行才需要标注**：

```
#	默认区室: 线粒体基质
底物	产物	酶
柠檬酸	异柠檬酸	顺乌头酸酶                      ← 都在基质，不用写
丙酮酸@细胞质	丙酮酸@线粒体膜间隙	VDAC 外膜通道    ← 跨区室，两端都标
```

区室必须是 `data/compartments.tsv` 里 20 个叶区室之一。中文名和同义词都认（共 83 种写法），
所以 `细胞核`、`核内`、`核基质` 都会解析成 `nucleoplasm`。

**不能填容器。** `线粒体` 不是区室，要具体到 `线粒体基质` / `线粒体内膜` / `线粒体膜间隙` / `线粒体外膜`。
`内质网` 同理，要分 `粗面内质网` / `平滑内质网` / `内质网腔`。

这不是形式主义 —— 「尿素循环在线粒体」画不出图，「氨甲酰磷酸在基质」才画得出。

区室字段只放区室。物种（植物/动物）、组织（肝/外周）、膜侧另有字段，见下。

## 酶还是节点

**规则：在流动路径上的是节点，只加速另外两者转化的是边标签。**

```
己糖激酶    葡萄糖→G6P，酶本身不参与流动      → 填「酶」列
复合体 I    电子从 NADH 进、从 CoQ 出，穿过它  → 是节点
```

看到「…酶」结尾的词，默认填到**酶**列，不要开新节点。
例外是有电子或质子穿过的载体复合体：复合体 I–IV、ATP 合酶、细胞色素 c、辅酶 Q。

这些例外不写死在代码里 —— 只要在 `data/nodes/` 里声明过，校验器就认它是节点。
以后遇到新的载体复合体，加一行声明即可，不用改程序。

转运体同理，**转运体是酶，不是节点**：

```
错：丙酮酸胞质 → VDAC → MPC → 丙酮酸基质        ← VDAC 不是物质
对：丙酮酸@细胞质 → 丙酮酸@线粒体膜间隙   酶=VDAC 外膜通道
    丙酮酸@线粒体膜间隙 → 丙酮酸@线粒体基质   酶=线粒体丙酮酸载体 MPC
```

移动的是物质，转运体是催化者。VDAC、MPC、ANT、CACT、CPT1/2 全部填酶列。

## 辅因子不连边

ATP、NADH、Pi 这些辅因子**写在反应式里，不当节点**：

```
葡萄糖	葡萄糖-6-磷酸	己糖激酶	否	葡萄糖 + ATP → G6P + ADP
```

底物/产物列只写主链两端，ATP 和 ADP 出现在反应式里就够了。

原因很实际：如果每条消耗 ATP 的反应都连一条边到 ATP 节点，那个节点会长出几十条边穿过整张图。
已核对的糖酵解 10 条反应里，0 条以辅因子为端点，但反应式里都带着 —— 这个规则本来就在数据里。

编译器会把反应式中的 ATP、NADH、Pi、共同底物和共同产物写入 `reaction.participants`，并汇总到 `participantCatalog`。学习模式可在反应详情中点击这些参与物，查看并跳转其出现的其他代谢场景；它们仍不会进入默认主图。`source=endpoint` 表示 TSV 主端点，`source=equation` 表示由反应式保守解析，后者不能代替人工科学审校。

**例外：当辅因子本身就是这条反应的主角时，它是节点。**
比如 ANT 搬运 ATP、ATP 合酶生成 ATP，这时候 ATP 是主链。

## 分叉怎么写

`底物`/`产物` 是画箭头的主链，`反应式` 是真实化学。产物多于一个时，主链只选一个：

```
果糖-1,6-二磷酸	磷酸二羟丙酮	醛缩酶	是	F-1,6-BP ⇌ DHAP + G3P	已核对	分叉：另一产物 G3P
```

主链选 DHAP，因为下一步 TPI 把它转成 G3P，路径是连续的。另一个产物写进备注。
哪个产物接主链需要你判断 —— 选能让路径走下去的那个。

## 什么时候写节点文件

只有需要额外属性时。绝大多数节点由反应自动推导，不用写。

```
名称	区室	膜侧	别名	物种	组织	备注
细胞色素 c	线粒体膜间隙	膜间隙侧	Cyt c			松散附着于内膜外表面
ATP 合酶	线粒体内膜	两侧	复合体 V			质子穿过它，所以是节点
```

- **膜侧**：`基质侧` / `膜间隙侧` / `胞质侧` / `腔侧` / `胞外侧` / `两侧`。区室回答「在哪个腔」，膜侧回答「朝哪一面」
- **别名**：用 `|` 分隔，将来做搜索用
- **物种**：只有植物特异的才填 `植物`
- **组织**：`肝` / `外周` 这类。酮体在肝生成、在外周利用，靠这个字段区分

膜侧不要写进区室列。`琥珀酸@线粒体基质 / 内膜` 会被当成一个新区室，而它其实就是基质。

## 怎么检查自己录的对不对

```
node tools/validate.js
```

分三档输出：

- **错误** — 必须修，退出码 1。区室不存在、酶填进了底物列、可逆列写了别的字、同文件内重复
- **提醒** — 可以先放着。酶为空、跨文件同一反应酶名不一致
- **等待转录** — 进度指示，不是问题。某节点已有坐标或属性，但还没有反应用到它

校验器自己也有自测，确认它不会永远说「无错误」：

```
node tools/selftest.js
```

最常见的错误是**漏打制表符**。TSV 里连续两个制表符表示空列，少打一个后面全串位。
校验器会直接指出来，但用能显示制表符的编辑器（VS Code 开 `Render Whitespace`）能提前避免。

Excel 可以直接打开 TSV，但**存回时要选「文本制表符分隔」**，别存成 xlsx 或 csv。

## 建议的转录顺序

已核对的 5 条通路已经导入，你不用重录：

```
glycolysis.tsv   10 条     tca.tsv    9 条
etc.tsv          15 条     pdh.tsv    1 条
transport.tsv    15 条
```

全部 54 条规范场景通路现在均已有 TSV；历史合并转运文件 `transport.tsv` 也已接入第 55 个 scene-data 导航入口。当前 348 行中 50 行「已核对」、247 行「已终审」、51 行「待审校」。历史状态字段不能替代证据门禁：247 行已终审中目前仅 22 行带机器可识别引用。原 58 行队列的逐项结论见 `data/review-log.tsv`，规则见 `docs/scientific-review-policy.md`。

剩余转录任务为 0；原 58 行待审校记录已完成一轮逐项复核，其中 7 行提升、51 行保留。下一步按台账原因拆分这 51 行，并为历史已终审记录补齐可验证证据。以下顺序保留用于后续新增或拆分通路：

1. **先录一条你最熟的**（比如糖异生或磷酸戊糖途径）。录完跑一次校验，看格式顺不顺手
2. **再录同区室的邻居** — 糖代谢那几条都在细胞质，默认区室一样，连着录最快
3. **跨区室的放后面** — 尿素循环、肉碱穿梭这类要标 `@区室`，等格式熟了再动
4. **植物特异的最后** — 淀粉、氮同化、硫同化、乙醛酸循环，这几条要填 `物种=植物`

一条通路一个文件，`data/reactions/` 下新建即可。文件头三行照抄现成的改：

```
#	通路: 磷酸戊糖途径	Pentose phosphate pathway
#	默认区室: 细胞质
#	来源: PDF 左中磷酸戊糖区
底物	产物	酶	可逆	反应式	审校	备注
```

`来源` 记 PDF 上的大致位置，方便以后回去核对。旧数据里 54 条通路的 `source` 都在，可以照抄。

**录完一条就能在网页上看到那条通路的节点网络** — 不用等全部录完。

## 环形通路：汇聚边

这一条是转录环形通路时最容易漏的，漏了图会画成开链。

TCA 化学上是环，但如果每条反应只记一个底物，拓扑上就断了：

```
柠檬酸合酶：草酰乙酸 + 乙酰辅酶 A → 柠檬酸     ← 两个底物
只记一个：  乙酰辅酶 A → 柠檬酸              ← 草酰乙酸出度变 0，环断在这里
```

结果是 9 个节点 8 条边、无有向环，布局算法只能按开链摆。

**正确做法：两个底物各写一行。**

```
草酰乙酸	柠檬酸	柠檬酸合酶	否	草酰乙酸 + 乙酰-CoA + H₂O → 柠檬酸 + CoA-SH	已核对	汇聚：另一底物乙酰辅酶 A
乙酰辅酶 A	柠檬酸	柠檬酸合酶	否		已核对	入口边
```

补上之后环闭合成 8 个节点，乙酰辅酶 A 落在环外作为入口 —— 这就是生化上的真实结构。

**哪个底物走主链？被这个环自己再生出来的那个。**

| 通路 | 主链底物 | 入口底物 |
|---|---|---|
| 三羧酸循环 | 草酰乙酸 | 乙酰辅酶 A |
| 尿素循环 | 鸟氨酸 | 氨甲酰磷酸 |
| 苹果酸–天冬氨酸穿梭 | 草酰乙酸 | — |
| 酮体生成与利用 | 乙酰辅酶 A | — |
| 乙醛酸循环 | 草酰乙酸 | 乙酰辅酶 A |
| 蛋氨酸循环 | 蛋氨酸 | — |

**校验器查不出漏掉的汇聚边** —— 少一条边在它看来只是少一条反应。但布局工具会报拓扑：

```
node tools/layout.js
```

如果某个环形通路显示「开链」而不是「环形」，就是汇聚边漏了。TCA 现在显示
`环形+9个链尾`，说明 8 节点的环认出来了。

已录入但仍需重点审校汇聚边的 5 条环形通路：乙醛酸循环、苹果酸–天冬氨酸穿梭、酮体、尿素循环、蛋氨酸循环。
