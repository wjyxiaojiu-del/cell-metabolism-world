# 细胞代谢世界地图 PRD

## 1. 文档状态

- 版本：v0.1
- 日期：2026-08-04
- 状态：产品方向与视觉底图已确认，进入首版数据与交互设计
- 目标平台：Web 优先，兼容平板浏览器
- 首版用户：医学生、生物化学专业学生；第二阶段支持教师课堂演示

## 2. 产品概述

“细胞代谢世界地图”是一张可缩放、可探索、可点击的完整动物细胞地图。细胞本身是首屏空间，细胞器是真实的空间锚点，代谢物是地图上的节点，反应是节点之间的连接线，酶贴在线路边上，调节因子通过激活或抑制关系连接到反应。

PDF《生物化学代谢总图新版-亮亮》只作为首版知识来源和关系校对依据，不复制其框框、版式或坐标。产品会从 PDF 中整理出结构化知识，再在细胞底图上重新创建一个个节点和连接。

## 3. 产品目标与非目标

### 3.1 目标

1. 让用户从“整个细胞”视角理解代谢发生的空间位置。
2. 让用户能够沿着物质、反应或酶探索上下游关系。
3. 将糖酵解、三羧酸循环和氧化磷酸化做成首版相互连接的核心路径。
4. 为后续接入 PDF 全量内容、更多细胞器和可视化编辑器保留数据结构。

### 3.2 非目标

- 首版不做可视化编辑器和多人协作。
- 首版不让图像生成模型直接生成正式的代谢文字、酶名或箭头。
- 首版不以临床病例和疾病知识为主线；临床内容后置。
- 首版不复刻 PDF 的分栏卡片式布局。

## 4. 已确认的视觉方向

- 采用完整横向透明动物细胞作为底图。
- 采用浅蓝透明细胞质、紫色细胞核、蓝色内质网、橙色大型线粒体、珊瑚粉高尔基体的教材级 3D 插画质感。
- 当前用户确认的底图版本具备：右上核区、左下大型线粒体、右下高尔基体、右侧内质网以及足够的细胞质留白。
- 底图只提供世界空间；动态节点和线路由 Canvas/SVG/WebGL 图层重新绘制。
- 不使用深色科幻 HUD、后台仪表盘、固定侧栏或 PDF 风格的彩色框块。

## 5. 首屏与地图层级

### 5.1 全景层

显示完整细胞、细胞膜、细胞核、内质网、高尔基体、线粒体和主要代谢路径的低密度主干。节点以简化圆点显示，标签以少量核心枢纽为主。

### 5.2 区室层

用户放大到细胞器附近后，显示该区室的主要通路和跨区室连接。例如，丙酮酸从细胞质进入线粒体，乙酰辅酶 A 在基质中连接 TCA 循环。

### 5.3 反应层

继续放大后，显示每个物质节点、反应线、箭头方向、酶徽标、辅因子和调节关系。线路按真实路径弯曲，避免直线堆叠。

### 5.4 细节层

显示反应步骤、反应式、酶的作用、底物与产物、辅因子、可逆性、激活/抑制信息及来源说明。

## 6. 节点与关系模型

产品采用“知识实体”和“画布实例”分离的模型。

### 6.1 知识实体

- `Organelle`：细胞器或细胞区室，如细胞质、线粒体基质、线粒体内膜、细胞核。
- `Pathway`：通路，如糖酵解、TCA 循环、氧化磷酸化。
- `Metabolite`：物质实体，如葡萄糖、丙酮酸、乙酰辅酶 A、ATP、NADH。
- `Reaction`：反应实体，保存一个反应的底物、产物、方向、可逆性、区室和来源。
- `Enzyme`：酶或酶复合体，保存名称、EC 编号、作用描述、同工酶和来源。
- `Regulator`：激活剂、抑制剂或调节状态。
- `Evidence`：来源、版本、人工审核状态和置信度。

### 6.2 画布实例

- `SceneNode`：一个可见的画布节点，引用一个知识实体并保存 `x/y`、所属区室、缩放可见范围、颜色、大小和标签策略。
- `SceneEdge`：一条可见连接线，引用 `reactionId`，保存起点、终点、方向、线型、颜色、路径控制点和可见范围。
- `EnzymeBadge`：贴在线路边上的可点击酶徽标；它可以是独立的交互命中区域，但视觉上不脱离反应线。
- `PortalLink`：同一物质在不同区室或通路中的视觉实例之间的关联，例如丙酮酸在细胞质节点与线粒体入口节点之间的转运关系。

同一种物质拥有统一的知识实体 ID，但允许在不同空间出现多个画布实例。点击任一实例时，其他同物质实例及其相关线路可以同步高亮。

## 7. 节点创建和布局原则

1. 每个反应步骤都重新创建物质节点和连接线，不搬运 PDF 的框块。
2. 节点位置由产品团队根据细胞器、阅读方向、路径连续性和拥挤程度重新编排。
3. 首版采用人工策划坐标，未来可增加自动布局辅助，但自动布局不能覆盖人工锚点。
4. 物质是主节点；反应是独立关系实体；酶贴在线边；调节因子作为独立关系节点。
5. 代谢枢纽如丙酮酸、乙酰辅酶 A、ATP、NADH 可以有更高视觉权重，但仍保持为普通知识节点。
6. 节点沿着自然曲线路径分布，不使用固定卡片、表格或模块框。
7. 同一条线路在全景层只显示主干，放大后再展开为详细节点，避免首屏过载。

## 8. 首版节点布局

### 8.1 细胞质：糖酵解与相关连接

在左上至中央细胞质中创建葡萄糖、葡萄糖-6-磷酸、果糖-6-磷酸、果糖-1,6-二磷酸、甘油醛-3-磷酸、丙酮酸等节点，并补充 ATP/ADP、NAD+/NADH、Pi 等辅因子连接。

### 8.2 线粒体基质：丙酮酸氧化和 TCA 循环

在大型线粒体基质中创建丙酮酸、乙酰辅酶 A、柠檬酸、异柠檬酸、α-酮戊二酸、琥珀酰辅酶 A、琥珀酸、延胡索酸、苹果酸和草酰乙酸节点，形成闭环并连接 NADH、FADH2、CO₂ 和 GTP/ATP。

### 8.3 线粒体内膜：氧化磷酸化

沿线粒体内膜创建复合体 I、II、III、IV、细胞色素 c、质子梯度和 ATP 合酶的交互节点。该区域要表达电子流方向、质子转运和 ATP 生成，但不把它画成装饰性电路板。

### 8.4 跨区室连接

至少支持丙酮酸进入线粒体、乙酰辅酶 A 与脂肪酸氧化汇合、NADH/FADH2 进入呼吸链、ATP/ADP 在细胞质与线粒体之间的关系。

## 9. 核心交互

- 平移：拖动画布探索整个细胞。
- 缩放：支持鼠标滚轮、触控板和平板双指缩放。
- 点击物质：显示浮动卡片，并高亮其生成、消耗、转运和调节关系。
- 点击酶：高亮对应反应线、底物和产物；浮卡显示酶作用、反应式和辅因子。
- 点击反应线：显示反应详情，并提供聚焦上游、下游和所在区室的操作。
- 点击调节因子：显示激活/抑制方向和作用目标。
- 点击细胞器：聚焦该区室并降低其他区域视觉权重。
- 搜索：支持物质、酶、反应和通路搜索，定位后自动放大并打开浮卡。
- 面包屑：显示“细胞 > 线粒体 > 基质 > TCA 循环”等当前位置。
- 清除选择：恢复全景视觉状态。

### 9.1 浮动卡片内容

浮卡优先贴近被点击对象显示，保持地图探索感；卡片可展开为完整详情页。详情至少包括名称、别名、所在区室、参与通路、上下游关系、酶、辅因子、调控信息、来源和审核状态。

## 10. 内容与数据流程

1. 对 PDF 进行分区截图和文字/图形人工核对。
2. 将物质、反应、酶、调节和区室拆成结构化实体。
3. 用 KEGG、Reactome、UniProt 等权威来源交叉校对；PDF 中无法确认的内容标记为待审核。
4. 为每个实体保留来源页码、截图区域和人工审核记录。
5. 首版只加载糖酵解、TCA 和氧化磷酸化的完整数据；其余通路可预留入口和数据结构。
6. 画布坐标独立于 PDF 坐标，所有正式展示线路均由数据驱动渲染。

## 11. 非功能需求

- Web 首屏应在现代笔记本上 3 秒内显示完整细胞底图和基础交互层。
- 平移和缩放时保持流畅；详细节点按区室和缩放级别懒加载。
- 在至少 2,000 个可见节点/连接线范围内保持可用的交互响应。
- 支持桌面浏览器和横屏平板；触控目标不小于 40px。
- 文字和线路具备足够对比度；提供减少动画选项。
- 图片加载失败时显示可读的细胞轮廓和重试提示，不阻塞数据层。
- 每个数据实体拥有来源和审核状态，避免生成图片文字成为事实来源。

## 12. 首版里程碑

1. 数据审计：完成 PDF 首版三条路径的物质、反应、酶和来源清单。
2. 地图底层：接入确认的细胞底图，完成平移、缩放、区室命中区域和基础节点渲染。
3. 三条核心通路：完成糖酵解、TCA、氧化磷酸化的节点和连接关系。
4. 交互层：完成酶贴线、浮动卡片、高亮上下游、搜索和面包屑。
5. 教学验证：邀请医学生完成指定探索任务，修正节点密度、命名和线路可读性。

## 13. 验收标准

- 打开页面首先看到一整个细胞，而不是分区网页或仪表盘。
- 物质、反应、酶和调节因子均可独立定位和点击。
- 点击一个物质时，只高亮与其相关的生成、消耗、转运和调节关系。
- 点击一个酶时，能明确看到其作用反应、底物、产物和辅因子。
- 糖酵解、TCA 和氧化磷酸化在数据层和画布层互相连接。
- 节点和线路由结构化数据生成，不能依赖图片中的文字或箭头。
- PDF 的知识关系被吸收，但最终视觉不复制 PDF 的框块布局。
- 页面在桌面和横屏平板上均可平移、缩放和查看详情。

## 14. 主要风险与应对

- PDF 字体或图形识别错误：保留原图截图、来源页码和人工审核状态。
- 节点过密导致线路不可读：使用语义缩放、路径分层、局部聚焦和人工坐标。
- 3D 底图过亮或过饱和：在渲染层增加可调暗度和局部遮罩，不重绘知识内容。
- 同一物质跨多个区室重复出现：使用统一实体 ID 和 PortalLink 关联。
- 全量 PDF 数据过大：按区室、通路和缩放级别分块加载。

## 15. 当前决策

- 采用完整细胞作为地图首屏。
- 采用“物质节点 + 反应连接线 + 酶贴线 + 调节关系”的表达。
- PDF 是知识来源，不是空间映射模板。
- 首版先完成糖酵解、TCA 和氧化磷酸化。
- 视觉底图已获得用户确认，下一步进入数据清单和交互原型设计。
