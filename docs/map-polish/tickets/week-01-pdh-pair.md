# PDH 双图垂直切片 tickets

## PDH-L1：学习图空间入口

前置：PDH 数据中的 VDAC 与 MPC 运输反应保持不变。  
交付：胞质、外膜、膜间隙、内膜、基质五个空间带，以及胞质丙酮酸 → VDAC → 膜间隙丙酮酸 → MPC → 基质丙酮酸。  
验证：先写失败浏览器断言；VDAC 可逆、MPC 单向且标注 H⁺同向输入。

## PDH-L2：E1/E2/E3 与五辅酶接力

前置：PDH-L1 完成。  
交付：E1/TPP 脱羧与 CO₂、E2/硫辛酰胺摆臂与 CoA-SH、E3/FAD 再氧化及 NAD⁺→NADH + H⁺；乙酰-CoA 出口连接 TCA。  
验证：学习主图语义节点、产物分支、不可逆标志和教材图内容一致。

## PDH-E1：专家图双机制区

前置：学习图科学边界冻结。  
交付：专家覆盖层分成跨膜输入区与 PDH 复合体区，补齐 VDAC/MPC，同时保留 E1/E2/E3 五辅酶接力。  
验证：390/768 标签高度、碰撞、裁切和页面溢出专项测试先红后绿。
