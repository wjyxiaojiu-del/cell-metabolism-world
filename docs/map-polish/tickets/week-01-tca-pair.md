# TCA 双图垂直切片 tickets

## TCA-L1：学习图四段循环

前置：TCA 数据反应保持八个经典酶边界，图数据中的第二条柠檬酸合酶边只承担闭环连接。  
交付：碳进入、两次氧化脱羧、底物水平磷酸化/内膜电子接力、OAA 再生四段结构，以及九个代谢物语义节点。  
验证：先写失败浏览器断言；闭环、反应方向、八个酶锚点和 OAA 再生均可由公共 DOM 行为核对。

## TCA-L2：每轮净收支与 SDH 边界

前置：TCA-L1 完成。  
交付：三处 NADH、两处 CO₂、一处 GTP、SDH 酶内 FAD→CoQH₂，以及中央每轮净收支卡。  
验证：主图不得出现游离 FADH₂输出；SDH 必须同时标注内膜复合体 II 和 CoQ 电子受体。

## TCA-E1：专家图环路与收支双阅读区

前置：学习图科学边界冻结。

验证：390/768 标签高度、碰撞、裁切和页面溢出专项测试先红后绿。
