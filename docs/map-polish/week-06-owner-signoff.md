# 第 6 周：负责人签核收口与最终审计准备

## 上位目标

第五周内部施工目标已达到 42/42；第六周不新增产品功能，不扩展核心通路范围，只完成负责人逐图签核支持和最终总审计准备。

## 本周目标

1. 负责人按通路对查看 21 条学习地图与 21 条专家地图。
2. 每条通路在 390、768、1440 三档实际操作并记录确认或退回。
3. 通过状态必须由负责人填写确认日期；退回状态必须保留问题说明。
4. 使用只读审计命令核对签核表、内部台账、评分、P0/P1 和 canonical final 证据的一致性。
5. 对退回项只处理对应通路对，重新生成该通路的 final 证据并运行针对性回归。
6. 42/42 确认后再运行一次 `npm test`，形成最终总审计结果。
