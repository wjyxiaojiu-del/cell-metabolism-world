# 学习地图与专家地图打磨工作台

本目录把 `docs/continuous-product-roadmap.md` 转换为逐张可执行、可评分、可复审的工作台。

## 当前正式目标

项目唯一总目标就是原“第 5 周结束状态”：完成 21 条核心通路的学习地图和专家地图内部打磨，共 42 个独立验收对象，并达到 42/42 全部通过。五周只表示施工顺序，不表示有五个并列目标。

每张地图必须同时满足：

- 总分不低于 90/100。
- 科学准确性不低于 24/25。
- P0、P1 问题均为 0。
- 完成 390、768、1440 三档截图和实际操作验收。
- 由项目负责人逐张确认通过。

两套地图全部通过前，不发布、不招募用户、不扩充产品范围。

任何单图、单专题或单周完成都只更新进度，不能把项目标记为完成。

## 状态定义

- `未审`：尚未完成第一轮人工查看。
- `已留证`：已有三档现状截图，但尚未完成评分。
- `处理中`：已登记问题，正在重做。
- `待复审`：修改完成，等待重新截图和评分。
- `已通过`：达到全部内部完成门槛。

状态不能因自动化测试通过直接改为 `已通过`。

## 每张地图的固定闭环

1. 保存三档现状截图。
2. 完成科学、教学、视觉、交互和跨设备评分。
3. 登记 P0–P3 问题。
4. 明确本轮唯一主要问题和最多两个次要问题。
5. 修改并运行针对性测试。
6. 重新截图、重新评分和人工复审。

## 截图留证规则

截图统一放入：

```text
docs/map-polish/evidence/
  learning/<pathway-id>/
  expert/<pathway-id>/
```

文件名固定为：

```text
YYYY-MM-DD-before-390.png
YYYY-MM-DD-before-768.png
YYYY-MM-DD-before-1440.png
YYYY-MM-DD-after-390.png
YYYY-MM-DD-after-768.png
YYYY-MM-DD-after-1440.png
```

截图必须呈现当前地图主体和关键导航状态；不得只截局部来回避密度、溢出或层级问题。

三档证据统一使用 `node tools/capture-map-polish.js --pathway=<id> --phase=before|final` 生成；可用 `--modes=learning` 或 `--modes=expert` 只更新单侧证据。
