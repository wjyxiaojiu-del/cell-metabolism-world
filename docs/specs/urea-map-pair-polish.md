## 唯一主问题

现有学习图把 11 条原始反应压成一条泛化横链，既没有完整五步循环，也无法读出线粒体基质与胞质的接力。专家图虽显示五步、ORNT1 和两份氮，但所有机制集中在同一张背景上，移动端标签拥挤，NAG、citrin、三份原子来源和 3 ATP / 4 个高能磷酸键的能量账没有形成清晰层级。

## 科学边界

1. 哺乳动物尿素循环主要在肝细胞完成；前两步位于线粒体基质，后三步位于胞质。
2. CPS1 使用 NH₄⁺、HCO₃⁻和 2 ATP 生成氨甲酰磷酸；N-乙酰谷氨酸 NAG 是 CPS1 的必需变构激活因子，由 NAGS 生成，不是循环的化学计量底物。
3. OTC 用鸟氨酸和氨甲酰磷酸生成瓜氨酸；不得把 OTC 画成只接受氨甲酰磷酸的单底物反应。
4. ORNT1 / SLC25A15 跨线粒体内膜耦联鸟氨酸输入与瓜氨酸输出；不得表现为两种分子自由扩散。
5. 胞质 ASS1 使用瓜氨酸、天冬氨酸和 ATP 生成精氨代琥珀酸，ATP 变为 AMP + PPi；天冬氨酸是尿素的第二份氮，可由 citrin / SLC25A13 支持的线粒体天冬氨酸输出提供。
6. ASL 把精氨代琥珀酸裂解为精氨酸与延胡索酸；延胡索酸连接苹果酸、草酰乙酸和天冬氨酸，构成天冬氨酸—精氨代琥珀酸旁路与 TCA 的接口。
7. 胞质 ARG1 水解精氨酸，释放尿素并再生鸟氨酸；鸟氨酸回到基质继续下一轮，本身不是净消耗物。
8. 每生成 1 分子尿素消耗 3 个 ATP，但由于 ASS1 将 ATP 裂解到 AMP + PPi，等价消耗 4 个高能磷酸键。
9. 尿素的两份氮分别来自 NH₄⁺与天冬氨酸，羰基碳来自 HCO₃⁻；不得把鸟氨酸或 NAG 画成尿素的净原子来源。
