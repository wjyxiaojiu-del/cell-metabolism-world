# 酮体生成与利用双地图打磨规格

状态：内部实施与复审完成，待项目负责人确认  
所属项目总目标：第 5 周终点——42/42 学习地图与专家地图全部通过

## 唯一主问题

现有学习图把肝脏生成和外周利用压成一条看似可双向运行的通用链，无法解释为什么肝只能净输出酮体；现有专家图虽标了 SCOT，但仍把两个组织的线粒体叠在同一空间。双图必须改成“肝线粒体生成 → 血液运输 → 外周线粒体利用”的双组织旅程。

## 科学边界

1. 生理性酮体生成主要发生在肝细胞线粒体基质；禁食/低胰岛素状态下，脂肪酸 β-氧化提供乙酰-CoA和较高的线粒体 NADH。
2. 两个乙酰-CoA先经硫解酶可逆缩合为乙酰乙酰-CoA；HMGCS2再加入一个乙酰-CoA形成 HMG-CoA，HMGCL裂解后生成乙酰乙酸并返还一个乙酰-CoA，净碳账为 2 个乙酰-CoA→1 个四碳酮体。
3. 肝线粒体 BDH1 以 NADH还原乙酰乙酸为 D-β-羟丁酸；两者比值反映线粒体 NADH/NAD⁺氧化还原状态。β-羟丁酸在化学结构上不是酮，但按代谢定义属于酮体。
4. 少量乙酰乙酸可自发脱羧形成丙酮和 CO₂；丙酮主要呼出，不作为主燃料回收。
5. 乙酰乙酸和 D-β-羟丁酸进入血液，跨细胞质膜可由单羧酸转运蛋白 MCT参与；线粒体酮体转运分子的身份仍不完全确定，不在图中虚构具体载体。
6. 外周有线粒体的组织先以 BDH1把 D-β-羟丁酸氧化回乙酰乙酸并生成 NADH；SCOT/OXCT1把琥珀酰-CoA的 CoA转给乙酰乙酸，生成乙酰乙酰-CoA和琥珀酸，不直接消耗 ATP。
7. 乙酰乙酰-CoA再经硫解酶形成 2 个乙酰-CoA进入 TCA。肝细胞缺少 SCOT/OXCT1，不能利用自己生成的酮体，从而避免无效循环。
8. 红细胞没有线粒体，不能利用酮体；心肌、骨骼肌、肾和长期禁食时的脑可利用。酮体代谢产生 ATP 的位置是外周 TCA/呼吸链，不是血液运输或肝生成步骤。

参考依据：[NCBI/PMC：HMGCS2/HMGCL、BDH1、MCT与肝缺少 SCOT](https://pmc.ncbi.nlm.nih.gov/articles/PMC8922216/)、[NCBI/PMC：生成与利用采用不同不可逆承诺步骤以避免无效循环](https://pmc.ncbi.nlm.nih.gov/articles/PMC4176946/)、[NCBI Bookshelf：肝线粒体生成与外周 SCOT 利用](https://www.ncbi.nlm.nih.gov/books/NBK554523/)。

- 专用布局 `ketone-liver-blood-periphery`，分 hepatic-ketogenesis、circulation-redox、extrahepatic-ketolysis、tissue-boundary 四区。
- 保留 7 条原始反应列表；至少 16 个教学节点、7 个核心事件。
- 肝生成和外周利用使用独立的乙酰乙酸、β-羟丁酸、乙酰乙酰-CoA节点，不允许用一条可逆边替代组织运输。
- 明确 HMGCS2/HMGCL、BDH1双向红氧、SCOT的琥珀酰-CoA→琥珀酸耦联、肝缺少 SCOT和外周 TCA出口。
