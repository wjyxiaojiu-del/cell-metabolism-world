# 转氨与氧化脱氨双地图打磨规格

所属项目总目标：第 5 周终点——42/42 学习地图与专家地图全部通过

## 唯一主问题

现有学习图把多个角色都显示为“谷氨酸”，无法看出氨基怎样从多种氨基酸汇入谷氨酸，也无法区分不释放游离氨的转氨与真正产生 NH₄⁺的氧化脱氨。专家图已有胞质—基质方向，但仍是一条横向示意线，缺少 ALT/AST实例、PLP角色、载体身份、GDH反应账和尿素循环两份氮的交接。

## 科学边界

1. 氨基转移酶把氨基酸的氨基转给 α-酮戊二酸，形成对应 α-酮酸和谷氨酸；反应通常可逆，依赖酶结合的磷酸吡哆醛 PLP。
2. 转氨只转移氨基，不直接释放游离 NH₄⁺。不同氨基酸需要相应氨基转移酶，通用“氨基酸”节点是类别模板，不代表单一分子或单一数据库反应。
3. ALT/GPT 的教材实例为丙氨酸 + α-KG ⇌ 丙酮酸 + 谷氨酸；AST/GOT 的实例为天冬氨酸 + α-KG ⇌ 草酰乙酸 + 谷氨酸。AST有胞质与线粒体同工酶，不能把 ALT/AST 都限定成单一区室的一种蛋白。
4. 胞质谷氨酸可由线粒体谷氨酸载体 GC1/GC2（SLC25A22/SLC25A18）与 H⁺同向输入基质；不得画成谷氨酸自由扩散穿过内膜。
5. 线粒体基质谷氨酸脱氢酶 GDH/GLUD 催化：谷氨酸 + NAD(P)⁺ + H₂O ⇌ α-KG + NH₄⁺ + NAD(P)H + H⁺。这是本图释放游离氨的步骤。
6. 哺乳动物 GDH受能量状态变构调节：GTP抑制，ADP与亮氨酸促进；学习图只需显示“能量状态调节”，专家图显示具体调节物。
7. 肝线粒体中，GDH释放的 NH₄⁺交给 CPS1，构成尿素的第一份氮；AST生成的天冬氨酸在胞质尿素循环提供第二份氮。转氨图只画交接口，不重复完整尿素循环。
8. α-KG是氮汇聚与 TCA碳骨架之间的接口；不得把转氨画成碳骨架消失，也不得暗示所有氨基酸都必须先释放游离氨。
