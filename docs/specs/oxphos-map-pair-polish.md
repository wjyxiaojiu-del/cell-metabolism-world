## 学习地图目标

初学者应在一张图上看清三件事：

1. **能量转换**：膜间隙 H⁺ 顺电化学梯度经 F₀F₁-ATP 合酶回流到基质，驱动基质侧 ADP + Pi → ATP。
2. **核苷酸交换**：ANT 以 ATP⁴⁻输出、ADP³⁻输入的方式交换基质与膜间隙的核苷酸。
3. **磷酸输入**：SLC25A3 将 Pi 与 H⁺同向带入基质；外膜 VDAC 连接膜间隙与细胞质。

## 用户可见结构

```text
膜间隙：H⁺ ───────────────┐
                           ↓
内膜：              F₀F₁-ATP 合酶
                           ↓
基质：           ADP + Pi ───→ ATP

细胞质 ADP ⇌ VDAC ⇌ 膜间隙 ADP ⇌ ANT ⇌ 基质 ADP
基质 ATP  ⇌ ANT  ⇌ 膜间隙 ATP ⇌ VDAC ⇌ 细胞质 ATP
细胞质 Pi  ⇌ VDAC ⇌ 膜间隙 Pi  ⇌ SLC25A3(+H⁺) ⇌ 基质 Pi
```

学习图应分成“质子回流与 ATP 合成”“ANT 核苷酸交换”“Pi/H⁺输入”三个可辨认通道，不再显示通用跨通路关联区。
