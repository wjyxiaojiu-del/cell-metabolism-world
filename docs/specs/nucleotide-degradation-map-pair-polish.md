# 核苷酸降解双地图打磨规格

所属项目总目标：第 5 周终点——21 条核心通路的 42 张学习地图与专家地图全部通过。

## 验收目标

- 学习图明确三段顺序：核苷酸去磷酸、核苷裂解、碱基按嘌呤/嘧啶分流。
- 嘌呤支路明确次黄嘌呤/鸟嘌呤最终到尿酸；嘧啶支路明确尿嘧啶到 β-丙氨酸、胸腺嘧啶到 β-氨基异丁酸。
- 补救回收作为“可回到核苷酸池”的接口表达，不虚构本通路未提供的补救反应。
- 专家图同时标出细胞质主场景、溶酶体输入边界、嘌呤/嘧啶终产物和有限结论。
- 390、768、1440 三档无横溢出、关键文字无碰撞或裁切。

## 科学边界

- 核苷酸酶：核苷酸 + H₂O → 核苷 + Pi。
- 核苷磷酸化酶：核苷 + Pi ⇌ 碱基 + 核糖-1-磷酸。
- 人类嘌呤分解以尿酸为主要终产物；嘧啶分解产物进入更小分子代谢。
- 补救合成与降解是相邻过程，本图只标接口，不把 APRT/HGPRT 反应冒充为降解主干。
