# 学习侧栏可读字号规格

日期：2026-09-06

## 问题

学习模式左侧“主题 / 专题通路”目录在桌面宽度下使用 9–11px 字号。中文名称、英文副标题和通路说明阅读吃力，层级也不够清晰。

## 已确认范围

- 整体提高左侧目录文字可读性，不只放大某一行。
- 保持现有蓝白玻璃卡片风格、侧栏宽度、内容和交互不变。
- 不新增功能，不改学习地图或专家地图数据。

## 验收标准

- 主题中文名称和专题通路中文名称的计算字号不低于 14px。
- 主题英文副标题和专题通路说明的计算字号不低于 11px。
- 目录开关和分组标题的计算字号不低于 11px，卡片右侧数量/编号不低于 12px。
- 主题卡片最小高度不低于 58px，专题通路卡片最小高度不低于 68px。
- 390、768、1440 三档不产生新的页面横向溢出或文字裁切。
- 现有主题选择、通路选择和活动态行为保持不变。

## 非目标

- 不扩大侧栏宽度。
- 不改变主题与通路数量、文案或顺序。
- 不改变地图、科学内容、签核状态或后续周门禁。
