# ETC 学习地图双入口重做规格

状态：已确认，进入实现  
所属总目标：第 1 周生物氧化双图 12/42

## 目标

电子传递链学习地图必须让初学者在一张图上看清：

1. NADH 经复合体 I 进入。
2. 琥珀酸的电子经复合体 II 内的 FAD/FADH₂ 进入；不得把游离 FADH₂ 画成跨膜底物。
3. 两路电子在 CoQ 池汇合，经复合体 III、细胞色素 c、复合体 IV 传给 O₂，并生成 H₂O。
4. 复合体 I、III、IV 向膜间隙侧转移质子，复合体 II 不泵质子。
5. ETC 的输出是质子动力势；ATP 合成属于下一张氧化磷酸化地图。

## 用户可见结构

```text
基质侧：NADH → 复合体 I ┐
                          ├→ CoQ → 复合体 III → Cyt c → 复合体 IV → H₂O
基质侧：琥珀酸 → 复合体 II ┘                              ↑
                                                             O₂

膜间隙侧：I、III、IV → H⁺积累 → 质子动力势
下一站：氧化磷酸化
```

## 交互要求

- 每个主节点保持可聚焦、可点击，并能打开真实反应详情。
- “下一站：氧化磷酸化”是明确按钮，点击进入 `oxphos` 学习地图。
- ETC 主图不显示 ATP 合酶、ADP 或 ATP 节点。
- 弱关联节点默认不占据 ETC 主图；只保留直接解释本通路的结构。

## 图片要求

- 保留原有内膜机制图的复合体 I–IV、CoQ、Cyt c、O₂/H₂O 与质子泵信息。
- ETC 页面裁去 ATP 合酶与 ATP 生成区域；`oxphos` 页面继续使用完整的氧化磷酸化图。
- 图片标题和说明必须明确“电子传递链”，不得继续写成 ETC 与 ATP 合成的混合结论。

## 跨设备要求
