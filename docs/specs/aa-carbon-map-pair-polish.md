## 唯一主问题

现有学习图只把“氨基酸类别 → 碳骨架 → 七类入口 → 生糖/生酮”串成四个泛化节点，无法回答“哪类氨基酸进入哪个入口”，移动端还会被参考图挤压。专家图虽列出七类入口，却把分流中心画成类似统一跨膜载体的“碳骨架跨区室接口”，既缺少具体氨基酸归宿，也没有把纯生酮、兼具生糖/生酮和不可净生糖的边界讲清。

## 科学边界

1. 去除氮后，20 种蛋白质氨基酸的碳骨架经各自不同的多步路径汇入七类中央代谢入口；这些是教学分类映射，不是七条由统一酶催化、具有统一计量的单反应。
2. 七类入口为丙酮酸、乙酰-CoA、乙酰乙酸/乙酰乙酰-CoA方向、α-酮戊二酸、琥珀酰-CoA、延胡索酸和草酰乙酸。
3. 丙酮酸、α-酮戊二酸、琥珀酰-CoA、延胡索酸和草酰乙酸可形成糖异生前体，因此属于生糖入口；乙酰-CoA与乙酰乙酸方向属于生酮入口。
4. 哺乳动物不能从乙酰-CoA或乙酰乙酸净生成葡萄糖；不得把“进入 TCA”误画成乙酰-CoA可净生糖。
5. 纯生酮氨基酸只有亮氨酸与赖氨酸；异亮氨酸、苯丙氨酸、苏氨酸、色氨酸和酪氨酸同时具有生糖与生酮去路；其余蛋白质氨基酸按本图教学边界归为生糖。
6. 七入口的常用教学映射：丙酮酸（丙氨酸、半胱氨酸、甘氨酸、丝氨酸、苏氨酸、色氨酸）；α-酮戊二酸（精氨酸、谷氨酸、谷氨酰胺、组氨酸、脯氨酸）；琥珀酰-CoA（异亮氨酸、蛋氨酸、苏氨酸、缬氨酸）；延胡索酸（苯丙氨酸、酪氨酸）；草酰乙酸（天冬氨酸、天冬酰胺）；乙酰-CoA/乙酰乙酸方向承担生酮分支。
7. 不同降解路径分布在细胞质和/或线粒体，不能画成所有“碳骨架”通过同一个载体跨膜；地图只表达最终入口分类，并明确区室依具体路径而异。
8. 碳骨架可供 TCA 氧化、糖异生或酮体/脂质方向使用；实际流向取决于组织与代谢状态，不能写成空腹时所有氨基酸必然产糖。
