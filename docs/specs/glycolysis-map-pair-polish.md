## 科学边界

本图只解释哺乳动物细胞质中的经典十步糖酵解：一分子葡萄糖先投入 2 ATP，裂解为两份三碳骨架，再在后半程形成 4 ATP、2 NADH 和 2 丙酮酸；净收支为 2 ATP 和 2 NADH。

十个事件按每分子葡萄糖计量：

1. 己糖激酶/葡萄糖激酶：葡萄糖 + ATP → G6P + ADP，不可逆。
2. 磷酸葡萄糖异构酶：G6P ⇌ F6P。
3. PFK-1：F6P + ATP → F-1,6-BP + ADP，不可逆且为承诺步骤。
4. 醛缩酶：F-1,6-BP ⇌ DHAP + GAP。
5. TPI：DHAP ⇌ GAP；此后每个后半程反应发生 2 次。
6. GAPDH：2 GAP + 2 Pi + 2 NAD⁺ ⇌ 2 1,3-BPG + 2 NADH + 2 H⁺。
7. PGK：2 1,3-BPG + 2 ADP ⇌ 2 3-PG + 2 ATP。
8. PGAM：2 3-PG ⇌ 2 2-PG。
9. 烯醇化酶：2 2-PG ⇌ 2 PEP + 2 H₂O。
10. 丙酮酸激酶：2 PEP + 2 ADP → 2 丙酮酸 + 2 ATP，不可逆。

净反应：

```text
葡萄糖 + 2 NAD⁺ + 2 ADP + 2 Pi
→ 2 丙酮酸 + 2 NADH + 2 H⁺ + 2 ATP + 2 H₂O
```

三处生理不可逆关卡是己糖激酶/葡萄糖激酶、PFK-1 和丙酮酸激酶；只有 PFK-1 应称为糖酵解承诺步骤。本轮不展开组织特异同工酶调控，也不把乳酸发酵混入十步主干，只在出口说明缺氧或无完整线粒体时需再生 NAD⁺。

参考依据：[Reactome R-HSA-70171](https://reactome.org/content/detail/R-HSA-70171)、[Reactome R-HSA-70467](https://reactome.org/content/detail/R-HSA-70467)、[Reactome R-HSA-71670](https://reactome.org/content/detail/R-HSA-71670)。
