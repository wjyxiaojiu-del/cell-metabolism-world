## 科学边界

本图包含两个连续但不同的过程：

1. **进入线粒体**：胞质丙酮酸经外膜 VDAC 到膜间隙，再由内膜 MPC1/MPC2 复合体与 H⁺同向进入基质。
2. **基质内不可逆氧化脱羧**：PDH 复合体以 E1、E2、E3 和 TPP、硫辛酰胺、CoA、FAD、NAD⁺完成底物接力，净反应为丙酮酸 + CoA-SH + NAD⁺ → 乙酰-CoA + CO₂ + NADH + H⁺。

VDAC 是外膜低选择性通道；MPC 是内膜丙酮酸载体；二者不能合并成一个“线粒体丙酮酸载体”。PDH 反应发生在线粒体基质，且在生理条件下按不可逆入口表达。

参考依据：IUBMB EC 1.2.4.1；Bricker et al., Science 2012, DOI 10.1126/science.1218099；Herzig et al., Science 2012, DOI 10.1126/science.1218530；Zhou et al., PNAS 2001, PMCID PMC64939。

### 学习地图

当前主图只是“丙酮酸 → VDAC → 丙酮酸 → MPC → 丙酮酸 → 乙酰-CoA”的通用单链，存在三个 P1：

1. 没有在主图中显示 CO₂、NADH + H⁺、CoA-SH 和 NAD⁺，初学者看不到完整净反应。
2. VDAC/MPC 跨膜运输与 E1/E2/E3 催化接力没有视觉分区，区室和机制被压成同一种节点。
3. 主图没有呈现 TPP、硫辛酰胺和 FAD 的角色，底部教材图虽有信息，但没有与可交互主线形成一致结构。

## 学习地图目标

学习主图采用“空间入口 + 三酶接力”双段结构：

```text
胞质丙酮酸 ⇌ VDAC ⇌ 膜间隙丙酮酸
                         ↓ MPC + H⁺
                    基质丙酮酸
                         ↓ E1 · TPP        → CO₂
                    羟乙基-TPP
                         ↓ E2 · 硫辛酰胺 + CoA-SH
                    乙酰-CoA               → TCA

还原硫辛酰胺 → E3 · FAD/FADH₂ → NAD⁺ → NADH + H⁺
```

必须让初学者一眼回答：

- 丙酮酸依次跨过哪两层膜、由谁运输？
- 三个碳如何变为两个碳的乙酰基，第三个碳去了哪里？
- E1、E2、E3 分别完成什么接力？
- 五种辅酶分别在哪一步参与？
- 乙酰-CoA 和 NADH 下一步分别进入哪里？

## 专家地图目标

- 入口继续使用能容纳胞质—外膜—膜间隙—内膜—基质全路径的线粒体总场景。
- 覆盖层明确分成“跨膜输入”和“PDH 复合体”两个机制区。
- 跨膜区必须出现 VDAC、膜间隙丙酮酸、MPC1/2 与 H⁺同向输入。
- 复合体区必须出现 E1/TPP 脱羧、E2 硫辛酰胺摆臂与 CoA 转乙酰、E3 FAD 再氧化及 NAD⁺→NADH + H⁺。
- 390/768 px 的关键标签高度不低于 10 px，标签无碰撞、无裁切，页面无横向溢出。
- 反应步骤列表仍只显示 `pdh` 自身 3 条反应。

## 跨设备要求

- 390 px：页面不横向溢出；学习图内部允许带提示的横向浏览，首屏先看到胞质到基质的入口；专家图两个机制区上下分层，不重叠。
- 768 px：学习图可看清完整空间入口和主要催化接力；专家图两个机制区可同时扫描。
- 1440 px：运输、复合体、产物去向形成连续阅读线，大图不留下无意义空区。
