## 性能改动

1. Nginx 为 HTML、JavaScript、JSON、CSS 与 SVG 启用 gzip。
2. `index.html` 保持 `no-cache`；带统一查询版本号的运行时 JS 使用 30 天 immutable 缓存。
3. 图片、字体与 SVG 使用 30 天 immutable 缓存。
4. 封面和专家地图共用 `1600×1200` WebP，避免进入专家地图时再次下载另一张 823KB 细胞图。
5. 平板手势期间关闭浮层的 backdrop-filter 和阴影合成，手势结束后自动恢复。
6. 专家地图继续使用 rAF 批处理和轻量 viewBox 更新。
