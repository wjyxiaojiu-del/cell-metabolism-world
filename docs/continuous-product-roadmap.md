## 1. 唯一总目标（原第 5 周结束状态）

完成 21 条核心通路的学习地图和专家地图内部打磨，共 42 张独立验收地图。只有同时达到以下全部条件，项目才算完成：

- 学习地图 21/21 已通过。
- 专家地图 21/21 已通过。
- 42/42 均有 390、768、1440 三档前后截图及实际操作验收。
- 42/42 总分不低于 90/100，科学准确性不低于 24/25。
- 全项目 P0=0、P1=0。
- 同一通路的学习地图与专家地图不存在事实、方向、区室或边界矛盾。
- 数据、布局、导航、移动端和全量 UI 门禁全部通过。
- 项目负责人已完成逐图人工确认。

这就是项目唯一总目标。任何单张修复、单个专题、某一周完成或自动化测试通过都只记为进度，不能宣告项目完成。

先把学习地图和专家地图本身做扎实，再谈用户。

完成与否不以测试数量、功能数量或发布状态判断，而以三个结果判断：

1. 初学者能沿学习地图看懂代谢主线，并知道下一步该看什么。
2. 专业学习者能在专家地图中确认区室、膜两侧、转运、方向和反应机制。
3. 每一张地图都经过项目负责人本人逐张查看并认可。

在两套地图全部通过内部门槛之前：

- 不招募外部测试用户。
- 不推进公开 Beta 或正式发布。
- 不扩充现有 55 条通路边界。
- 不增加账号、排行、社交等产品功能。
- 不进行与地图质量无关的框架重写。
- 不用“自动化测试通过”代替人工视觉和科学审查。

## 3. 学习地图完成标准

### 3.1 每条通路必须回答

1. 这条通路解决什么生理问题？
2. 它发生在哪里？
3. 输入和输出是什么？
4. 主线由哪些关键步骤组成？
5. 哪些步骤不可逆或受调控？
6. ATP、NADH、NADPH、FADH2 等能量与还原当量如何变化？
7. 它与相邻通路如何连接？
8. 学习者最容易混淆什么？

### 3.2 固定信息层级

学习地图保持六层阅读结构：

1. 专题总览
2. 通路导读
3. 机制主图
4. 步骤列表
5. 单步详情
6. 相邻通路出口

任一层都不能把下一层的全部信息提前堆出来。

### 3.3 视觉门槛

- 主反应方向一眼可见。
- 底物、产物、酶、能量、调控使用稳定且可复用的视觉语法。
- 无标签碰撞、低对比文字、主要连线被遮挡或背景抢主线。
- 390 px 下页面无横向滚动，核心标签可读。
- 768 px 下手势、侧栏和机制图不互相争夺空间。
- 1440 px 下信息密度充实但不散乱。
- 同一专题的地图具有一致的阅读习惯。

### 3.4 学习地图内部完成门槛

- 21/21 条核心通路完成逐张人工审查。
- 每条都有 390、768、1440 三档截图。
- 每条都有问题清单、评分和复审记录。
- 无已知科学性错误、关键标签碰撞和断裂步骤链接。
- 项目负责人确认该图能够直接用于讲解和复习。

## 4. 专家地图完成标准

### 4.1 固定生物层级

```text
完整细胞结构
  → 细胞器
    → 亚区室或膜侧
      → 通路机制
        → 单条反应
```

根场景只表达结构入口，不重新出现教学分类、专题分组或通路泳道。

### 4.2 每条专家通路必须检查

1. 入口是否直接到达最小生物学容纳场景。
2. 节点区室、膜侧和跨膜方向是否正确。
3. 跨区室步骤是否标出载体、酶或诚实的有限结论。
4. 反应线、转运线、调控线和关联线是否可区分。
5. 可逆反应、不可逆反应和循环闭合是否表达正确。
6. 背景是否帮助定位，而不是仅作装饰。
7. 节点密度是否合理，关键标签是否可读。
8. 机制图与步骤列表是否一致。
9. 证据是否足以支持当前结论强度。

### 4.3 专家地图内部完成门槛

- 21/21 条核心通路完成科学、空间、视觉、交互四项人工审查。
- 不再混用教学层级和生物空间层级。
- 跨区室反应能说明载体、方向和膜两侧关系。
- 主反应线无严重遮挡，关键节点无需猜测。
- 390、768、1440 三档均完成实际操作验收。
- 核心通路证据欠账优先处理，不能让弱证据支撑强结论。
- 项目负责人逐条确认专家地图达到可展示标准。

其余 34 条扩展通路暂不纳入本轮“地图完成”的定义，避免范围失控。

## 5. 统一评分门槛

每张学习地图和专家地图分别按 100 分评分：

| 维度 | 分值 | 核心问题 |
|---|---:|---|
| 科学准确性 | 25 | 反应、方向、区室、调控和证据是否正确 |
| 教学表达 | 20 | 学习者是否知道主线、重点和连接关系 |
| 视觉层级 | 20 | 视线顺序、密度、标签和连线是否清楚 |
| 交互闭环 | 20 | 进入、查看详情、返回和切换是否顺畅 |
| 跨设备可用性 | 15 | 390、768、1440 三档是否真实可用 |

通过条件：

- 总分不低于 90。
- 科学准确性不低于 24。
- 不存在 P0 或 P1 问题。
- 不允许用视觉高分抵消科学错误。
- 必须有人工截图审查，不能只依赖自动化测试。

## 6. 固定打磨流程

每张地图按同一个闭环处理：

1. **留证据**：保存当前三档截图和现状评分。
2. **审科学与教学**：先确认事实、主线、重点和认知顺序。
3. **重组视觉层级**：必要时重做构图，不把结构问题当作像素微调。
4. **实现与门禁**：采用测试驱动方式修改，并运行相关自动化检查。
5. **人工复审**：重新截图、评分、登记遗留问题并决定是否通过。

未通过的地图留在当前专题继续处理，不因日历到期自动进入下一专题。

## 8. 每周工作节奏

- 周一：完成本周全部通路的学习/专家双图现状审查和问题排序。
- 周二至周四：按“一个通路对”连续完成科学、视觉、交互与三端修复。
- 周五：处理本专题最后缺口，执行专题总回归和逐图人工复审。

在制品限制：同时只处理一个专题和一对学习/专家地图；一对未通过，不切换到下一对。

## 9. 问题优先级

- **P0**：科学错误、区室错误、方向错误、入口层级错误。
- **P1**：主线看不懂、关键标签不可读、导航断裂、移动端无法操作。
- **P2**：视觉语言不一致、密度不均、次要信息抢层级。
- **P3**：动画、装饰和非关键美化。

出现 P0 时暂停所有美化，先修事实和结构。

## 10. 必须重新规划的触发条件

出现任一情况，立即停下并重排，不继续机械执行周计划：

- 当前专题无法在本周达到全部通路成对通过。
- 现有底图不足以支撑正确表达，必须重制视觉资产。
- 当前数据模型无法表达区室、膜侧或证据强度。
- 移动端修复持续破坏桌面端或平板端。
- 学习地图与专家地图对同一事实产生矛盾。
- 工作开始漂移到扩通路、账号系统、发布或其他新功能。
